# Reseller controls update

- Fixed reseller price: **US$19 per 1-year code**.
- Minimum purchase: **10 codes (US$190)**.
- Paid quantity becomes the reseller's available code-credit limit.
- Admin can revoke unused credits.
- Admin can revoke individual unused generated codes.
- Admin can delete/disable reseller accounts while preserving historical sales/subscriber records.
- Reseller and admin reseller views use the main WORLD TV website logo.

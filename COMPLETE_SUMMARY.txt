API ROUTE MODULES (routes/):
✅ api-live-scores.js (public API)
   - GET /api/live-scores - Current live matches
   - GET /api/fixtures/upcoming - 7-day upcoming
   - GET /api/match/:id/broadcasts - Match broadcasts
   - GET /api/broadcasts/live - Currently live broadcasts
   - GET /api/team/:id/stats - Team statistics
   - GET /api/standings/:league - League standings

✅ admin-broadcasts.js (admin API)
   - GET /admin/broadcasts/channels - List channels
   - POST /admin/broadcasts/channels - Add channel
   - PUT /admin/broadcasts/channels/:id - Update channel
   - DELETE /admin/broadcasts/channels/:id - Delete channel
   - POST /admin/broadcasts/schedule - Schedule broadcast
   - PUT /admin/broadcasts/schedule/:id - Update broadcast
   - DELETE /admin/broadcasts/schedule/:id - Delete broadcast
   - POST /admin/broadcasts/streaming-link - Add streaming link
   - GET /admin/broadcasts/streaming-links/:id - Get links

✅ api-ai-images.js (AI API)
   - POST /api/ai/generate-match-banner - Generate artwork
   - GET /api/ai/placeholder-team - SVG placeholder
   - GET /api/ai/cache-stats - Cache statistics
   - POST /api/ai/clear-cache - Clear cache (admin)
